Şema Değişiklikleri (Migration 003)

✕ sale_payments — Para Birimi & Kur
Müşteri GBP/EUR/USD ile ödeme yapabildiği için her ödeme satırında para birimi ve o günün kuru saklanmalı. Aksi halde geçmiş satış raporları TL bazlı hesaplanamaz.
ALTER TABLE sale_payments
  ADD COLUMN currency       TEXT         NOT NULL DEFAULT 'TRY',
  ADD COLUMN exchange_rate  NUMERIC(12,6) NOT NULL DEFAULT 1,
  ADD COLUMN amount_base    NUMERIC(12,2) -- amount × exchange_rate (TRY)
  GENERATED ALWAYS AS (amount * exchange_rate) STORED;
✕ fx_rates — Günlük Kur Tablosu
Satış anındaki kuru satırda saklasak da, günlük kuru merkezi tutmak hem veri girişini kolaylaştırır hem de raporlarda tutarlılık sağlar.
CREATE TABLE fx_rates (
  id           UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  business_id  UUID NOT NULL REFERENCES businesses(id),
  rate_date    DATE NOT NULL,
  currency     TEXT NOT NULL,             -- 'GBP' | 'EUR' | 'USD'
  rate_to_try  NUMERIC(12,6) NOT NULL,   -- 1 GBP = ? TRY
  source       TEXT DEFAULT 'manual',    -- 'manual' | 'api'
  created_by   UUID REFERENCES profiles(id),
  created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (business_id, rate_date, currency)
);
✕ user_role enum — Muhasebe Rolü
Mevcut enum'a 'accounting' ekleniyor. Bu rol: satışları ve tedarikçi cari hesabını görebilir, ancak ürün/stok/fiyat değiştiremez.
ALTER TYPE user_role
  ADD VALUE 'accounting';

-- Muhasebe için ek RLS politikaları:
-- supplier_account_entries → SELECT izni (şu an sadece manager+)
-- supplier_payments       → SELECT izni
-- sales / sale_items      → SELECT izni (zaten var)
-- products                → INSERT/UPDATE yok
! İade & Fiyat Politikaları — businesses.settings
Kod değişikliği gerekmez; JSON settings alanına yeni anahtarlar ekleniyor. Tüm politika kararları bu alanda tutulacak.
-- businesses.settings alanına eklenen anahtarlar:
{
  "allow_cash_refund":           false,
  "exchange_window_days":        3,
  "default_reservation_hours":   24,
  "default_markup_multiplier":   3.0
}

-- categories tablosuna:
ALTER TABLE categories
  ADD COLUMN is_final_sale BOOLEAN NOT NULL DEFAULT false;
-- Bikini kategorisi: is_final_sale = true
! products — Fiyatlama Çarpanı
x3 formülünü sistemin bilebilmesi için ürün bazlı çarpan kolonu. Satış fiyatı öneri olarak hesaplanır, override edilebilir.
ALTER TABLE products
  ADD COLUMN markup_multiplier NUMERIC(5,2) DEFAULT 3.0;

-- Önerilen satış fiyatı:
